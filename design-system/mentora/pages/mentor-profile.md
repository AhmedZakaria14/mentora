# Mentor Profile — Mentora Design Override

Inherits `design-system/mentora/MASTER.md`.

## Page goal
Help a learner judge fit, understand the session, and choose the next action with minimal uncertainty.

## Overrides
- Trust-first layout: identity and expertise before purchase pressure.
- Desktop: main content + sticky booking sidebar.
- Mobile: booking card follows core expert introduction and becomes full width.
- Booking card must surface duration, price, next availability, Google Meet, timezone, and payment/cancellation messaging when implemented.
- Keep a single primary CTA: choose a time.
- Show real reviews only when available; demo profile copy must be labeled as demo.
- Skills are scannable chips, not decorative tags.
- Use clear section anchors for “مناسب لك إذا”، “عن الخبير”، “الخدمات”، “التقييمات”.
